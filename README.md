# compose-kanban-board-task

## 구현할 기능 목록

### 작업 카드

- [x] 작업 카드는 제목, 설명, 태그, 담당자를 가진다.
  - 설명과 태그는 빈 값일 수 있다.
  - 제목과 담당자는 필수로 값을 가져야 한다.
- [x] 태그와 담당자 사이에 회색 라인을 표시한다.

### 제목

- [x] 제목은 빈(Empty) 텍스트일 수 없다.
- [x] 한 줄이 넘어가면 말줄임표를 활용한다.
- [x] 폰트 사이즈를 설명보다 크게 한다.

### 설명

- [x] 빈(Empty) 텍스트인 경우는 화면에서는 출력하지 않는다. 
- [x] 두 줄이 넘어갈 경우 말줄임표를 활용한다.
- [x] 색상을 회색으로 설정한다.

### 태그

- [x] 태그 텍스트가 공란(Empty)일 수 없다.
- [x] 태그 텍스트는 최대 5글자이다.
- [x] 태그는 최대 5개이다.
- [x] 태그 배경으로 회색 라운드 박스를 표시한다.

### 담당자

- [x] 담당자는 빈(Empty) 텍스트일 수 없다.
- [x] 한 줄이 넘어가면 말줄임표를 활용한다.
- [x] 사용자 아이콘을 표시한다.


## 구현해야하는 테스트 목록

## Model

### 설명

- [x] 설명 텍스트를 입력 시, 설명 객체가 생성된다. 
- [x] 빈 공란이 입력될 경우에는 객체는 생성되지만 isEmpty가 참이다. 
- [x] 공백 한칸으로도 isEmpty는 거짓이 된다.

### 담당자

- [x] 담당자는 빈 텍스트일 수 없다. 
- [x] 담당자 텍스트 입력시 name에 이름이 입력된다.

### 태그

- [x] 태그 텍스트가 공란(Empty)일 수 없다.
- [x] 태그 텍스트는 5글자를 초과할 경우 에러를 반환한다.
- [x] 태그는 최대 5개이다.

### 제목

- [x] 제목 텍스트 입력 시, text에 입력된다.
- [x] 제목에 공란은 입력될 수 없다.

## UI

### 작업 카드

- [x] 작업 카드는 제목, 설명, 태그, 담당자를 화면에 표시하고 있는지 검증한다.
- [x] 작업 카드가 설명이 빈 공란이여도 설명을 제외하고 표시해야한다.
- [x] 작업 카드가 태그이 빈 공란이여도 설명을 제외하고 표시해야한다.

### 제목

- [x] 한 줄이 넘어가면 말줄임표를 활용하여 화면에 표시되어야한다.

### 설명

- [x] 설명이 너무 길 경우 최대 2줄로 제한하고 말줄임표를 표시한다.

### 태그

- [x] 태그 텍스트가 공란(Empty)일 경우, 에러를 반환한다.
- [x] 태그는 최대 5개 표시될 수 있다.
- [x] 태그는 최대 5글자가 표시될 수 있다.

### 담당자

- [x] 담당자의 텍스트가 한 줄이 넘어가면 말줄임표를 활용한다.
- [x] 사용자 아이콘을 표시한다.

### 1. 컨테이너

- [x] 보드의 각 요소를 배치할 컨테이너를 Box로 선언

### 2. 제목

- [x] 보드의 제목을 표시할 텍스트 컴포넌트

- [x] 보드에 중간 내용을 표시할 텍스트 컴포넌트
- [x] 컨테이너의 가로 길이보다 표시할 문자열이 길 경우 문자열의 뒷부분을 말줄임표로 대치

### 4. 태그

- [x] 태그를 표시할 컨테이너

- [x] 각 태그의 내용을 표시할 텍스트 컴포넌트
    - [x] 최대 글자수는 5자로 제한
- [x] 태그의 최대 개수는 5개로 제한

### 5. 작성자

- [x] 아이콘과 사용자 이름을 표시할 컨테이너
- [x] 작성자의 이름이 컨테이너의 가로 길이보다 길 경우 문자열의 뒷부분을 말줄임표로 대치
- [x] 줄넘김을 허용하지 않음

# 2단계 - 칸반 보드 태스크(테스트 코드)

# 1. 카드 데이터 입력 테스트
## 1-1. 제목 검증
### 1-1-1. [ ]제목 미입력 오류
- 카드의 제목이 입력되지 않았을 경우 IllegalArgumentException을 발생시키는지 테스트

## 1-2. 태그 검증
### 1-2-1. [ ] 태그 개수 검증 테스트
- 태그의 총 개수를 검증
- 태그의 최대 개수는 5개
- 초과할 경우 IllegalArgumentException을 발생시키는지 테스트
### 1-2-2. [ ] 태그 글자수 검증 테스트
- 각 태그의 글자 수를 검증
- 한 태그당 허용되는 글자수는 5자
- 5자를 넘는 태그가 있을 경우 IllegalArgumentException을 발생시키는지 테스트

## 1-3. 작성자 검증
### 1-3-1. [ ] 작성자 닉네임 검증 테스트
- 카드의 작성자 닉네임이 입력되지 않았을 경우 IllegalArgumentException을 발생시키는지 테스트

# 2. 카드 UI 생성 여부 테스트

## case1. 제목 누락 테스트
- [ ] 필수 정보인 카드의 제목이 누락되었음에도 카드 컴포넌트가 생성되는지 테스트

## case2. 본문 미입력 테스트
- [ ] 본문에 입력할 내용이 없음에도 본문을 표시할 Box 컴포넌트가 생성되는지 검증

## case3. 태그 미입력 테스트
- [ ] 태그를 입력하지 않았음에도 태그를 표시할 Box 컴포넌트가 생성되는지 검증

## case4. 작성자 닉네임 누락 테스트
- [ ] 필수 정보인 작성자 닉네임이 누락되었음에도 카드 컴포넌트가 생성되는지 테스트

# 3. 태그 조건 테스트
## case1. 태그 개수 제한을 초과한 컴포넌트 생성 테스트

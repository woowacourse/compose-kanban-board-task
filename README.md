# compose-kanban-board-task

## 2단계 해야할 일 목록

> 칸반보드 아이템들이 동적으로 추가될 수 있고, 태그를 입력 받는 곳에 5개 제한을 걸지 않은 상태라고 가정

- [x] 파라미터가 많은 경우 개행 적용하기

### UI 테스트

- [x] 제목, 설명, 태그 그룹, 담당자가 모두 입력된 카드라면 화면에 모두 노출한다
- [x] 설명과 태그 그룹이 각각 빈 값으로 입력된 경우라면 제목, 담당자만 노출한다
- [x] 설명이 빈 값으로 입력된 경우라면 제목, 태그, 담당자만 노출한다
- [x] 태그 그룹이 빈 값으로 입력된 경우라면 제목, 설명, 담당자만 노출한다
- [x] 태스크 카드의 태그 그룹은 태그를 최대 5개까지만 노출한다

### 단위 테스트

- [x] 테스트 이름을 구체적으로 변경하기
- [x] 제목이 빈 텍스트라면 예외를 반환한다
- [x] 담당자가 빈 텍스트라면 예외를 반환한다
- [x] 태그가 5글자를 넘어가면 예외를 반환한다

## 구현할 기능 목록

### 작업 카드

- [x] 작업 카드는 제목, 설명, 태그, 담당자를 가진다.
    - 설명과 태그는 빈 값일 수 있다.
    - 제목과 담당자는 필수로 값을 가져야 한다.
- [x] 태그와 담당자 사이에 회색 라인을 표시한다.

### 담당자

- [x] 담당자는 빈(Empty) 텍스트일 수 없다.
- [x] 한 줄이 넘어가면 말줄임표를 활용한다.
- [x] 사용자 아이콘을 표시한다.
